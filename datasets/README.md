# Evaluation material
No human corpus was downloaded or scraped. Local smoke samples are generated by Meta MMS and labeled synthetic. These establish software execution, not population-level recognition accuracy.

For user-owned or legally licensed material, use `manifest.example.jsonl`. Every record includes a relative audio path, language, reference, speaker/session, dataset, split and sample rate. Keep audio under ignored `datasets/audio/`. Research model training must use phrase/speaker splits independent of evaluation. Verify each corpus license before download; AI4Bharat, FLEURS and OpenSLR have dataset-specific terms.
