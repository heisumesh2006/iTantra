# Experiment Methodology

Radio sweeps fix payload length 1024 bytes, packet size 256, BPSK and seeds 42–101 across 60 trials per Es/N0. Compare AWGN/Rayleigh and repetition1/3; raw BER references are used only when assumptions match. Mode comparisons reuse identical audio, language, packet policy and seed at 4/8/12/20 dB. Full payload recovery is binary per run; packet delivery is a separate rate. Include wire metadata/coding cost and separate computation from modeled airtime. Reference WER uses NFC and whitespace tokenization; CER uses codepoints including spaces/punctuation. Never interpret no-reference None as zero. Codec SI-SDR uses common sample rate and truncates to common length after decoder trimming; it is not perceptual quality. Semantic mode omits waveform similarity. Report sample source and count; synthetic utterances cannot substantiate a human-language ranking. Figure filenames trace directly to JSON/CSV under research/results. Do not train on evaluation phrases.
