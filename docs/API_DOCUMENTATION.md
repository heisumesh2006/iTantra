# Api Documentation

GET /api/v1/health, /capabilities, /languages, /models. POST /audio multipart file →201 measured audio metadata. GET /media/{UUID} downloads controlled media. POST /speech/transcribe {media_id,language}; POST /speech/synthesize {text,language}. POST /transmissions {media_id,mode,language,channel_config,...} →202 queued job; GET /transmissions, /transmissions/{id}, /transmissions/{id}/result. POST /transmissions/{id}/cancel; DELETE /transmissions/{id}. POST /channels/simulate {config,snr_values,trials} returns measured sweep/constellation. POST /experiments/run →202; GET /experiments, /experiments/{id}; POST /experiments/{id}/cancel. GET /metrics/summary or /metrics/comparison. GET /exports/{transmissions|experiments}/{UUID}?format=json|csv. POST /adaptive/recommend. Polling provides durable actual stage events. Proposed standalone /codecs/encode and /codecs/decode were consolidated into the tested transmission/comparison endpoints; Swagger is authoritative. Application failures are {error:{code,message}}; Pydantic validation uses 422 detail. X-Request-ID is returned per request. No arbitrary filesystem paths are accepted.
