# Packet Protocol

All fields are network byte order. Header `>2sB16sHHBBH` is 27 bytes: IT magic (2), version 1 (1), UUID session (16), zero-based sequence uint16 (2), packet total uint16 (2), mode uint8 (1), language uint8 (1), payload length uint16 (2). Append 1–1024 payload bytes and CRC32 uint32 (4) over header plus payload. Maximum 4096 packets. Modes 1/2/3 are conventional/neural/semantic; language IDs 1–6 are en/hi/kn/ta/te/ml. Strict parse checks version, bounds, length, IDs and CRC. Reassembly requires all sequences exactly once with consistent session metadata. Order is restored by sequence. UTF-8 is decoded only after complete byte reassembly; fragments may split code points without corrupting final reconstruction. No retransmission or partial text inference is implemented.
