# Database Design

storage/itantra.sqlite3 uses WAL and parameterized queries. schema_version handles idempotent migration v1. Tables: media (UUID, timestamp, controlled local path, JSON metadata), transmissions and experiments (config/status/result/error/stages), experiment_results (per-trial results), model_metadata (verification evidence), comparisons (reserved comparison metadata). Batch comparisons are persisted in experiments/results; the comparisons table is reserved and is not advertised as a separate implemented service. Large audio stays in files. Results retain configuration/seed and provider identity. Audio expiration deletes media metadata and files; historical metrics remain. Session deletion also removes its referenced source/receiver artifacts, including shared source files.
