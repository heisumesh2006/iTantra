# Tech Stack

Frontend: React 19, React Router 7, TypeScript strict, Vite 6, Lucide icons, Recharts 3, CSS design system. Backend: Python 3.10, FastAPI/Pydantic, NumPy, SciPy, SQLite standard library, SoundFile, imageio-ffmpeg. Optional ML: CPU PyTorch 2.7, Faster Whisper 1.2, Transformers 4.57, Safetensors, uroman. Validation: pytest, Ruff, Vitest, Playwright. SQLAlchemy, Tailwind and Motion were omitted to avoid unnecessary dependencies; the required behavior uses smaller compatible implementations.
