# User Guide

Launch http://127.0.0.1:5173. Overview links to the studio and research. Studio shares the uploaded source with Compression and Analytics while the tab remains open. Choose source language and communication mode, then configure the channel. Ideal channel is the first demonstration; AWGN makes noise visible; 100% erasure shows explicit failure. Speech Lab can independently transcribe, synthesize or roundtrip. Channel Lab makes real seeded arrays and exports them. Compression runs two codecs on the same sample. Analytics saves batch A/B/C results and exports CSV/JSON. History reopens saved results or deletes artifacts; media may have expired even while metrics persist. Live Demo is turn-based processing through the real software channel, not full-duplex RF. If a model is missing, follow the model-specific install message.
