# Radio Channel Model

Both constellations have unit symbol energy. BPSK maps 0→+1 and 1→−1. Gray QPSK pairs map I and Q signs divided by sqrt(2). Complex AWGN n has independent real/imaginary variance N0/2, N0=10^(−Es/N0_dB / 10). Rayleigh h~CN(0,1) independently per symbol; y=hx+n and ideal receiver CSI produces y/h before decisions. No mobility/coherence-time model is implied. Raw BER compares actual coded transmitted and demodulated bits before majority decoding, excluding erased packets. Controlled bit flips occur after demodulation. Repetition rate is 1/3 and increases wire symbols; Es/N0 remains per transmitted symbol. Analytical uncoded BPSK BER is 0.5 erfc(sqrt(Es/N0)); QPSK is 0.5 erfc(sqrt(Es/N0 / 2)). Framing, synchronization and perfect packet boundaries are simulation assumptions. Gross wire rate is bits / modeled airtime, whereas effective bits per speech second is a source-normalized transport cost.
