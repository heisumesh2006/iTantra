# Testing Guide

Run scripts/run-tests.ps1 for pytest, backend Ruff, frontend Vitest and TypeScript/production build. Backend tests cover symbol energy, odd QPSK bit vectors, strict packet/CRC bounds, missing/duplicate/foreign sessions, all six Unicode scripts, erasure/corruption, deterministic channel samples, wire bit accounting, resampling frequency preservation, real Opus roundtrip, API validation, media safety and durable jobs. Analytical BER uses 400,000 bits and a six-standard-error tolerance; noise-energy and Rayleigh BPSK references are separately checked. Vitest exercises API error/offline behavior and seed configuration. With real servers and synthetic fixtures generated, Playwright exercises upload→actual encode/DSP/decode→receiver playback, deliberate erasure failure, measured charts and nine routes at mobile width. Model smoke verification executes real providers but is not a recognition accuracy benchmark. Review VERIFICATION_REPORT for exact commands and results.
