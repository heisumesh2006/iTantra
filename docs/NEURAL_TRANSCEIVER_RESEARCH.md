# Neural Transceiver Research

The separate experiments/neural_features.py defines log-mel patches (40 mel bands ×32 frames), a 128-hidden-unit encoder/decoder with 32 real latent dimensions, per-sample latent power normalization and differentiable real AWGN. scripts/prepare-synthetic-research.py generates 24 unique MMS English phrases, split 16 train /4 validation /4 test, then makes patches only within each phrase. Normalization uses training data alone. MSE training uses Adam and selects the checkpoint on validation MSE. Safetensors stores model weights, NPZ stores normalization, JSON stores configuration/history. Evaluation reserves test phrases and uses seed 2026 across 0/5/10/15/20 dB. This is an idealized analog feature-channel experiment: no quantization, transmitted bitstream, reconstructed playable waveform, speech corpus generalization or speaker-disjoint claim. See measured training output only after the scripts complete.
