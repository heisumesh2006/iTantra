# Results And Limitations

See VERIFICATION_REPORT.md and local research/results for actual measured evidence. Synthetic MMS samples were used for software smoke tests and trainable-extension material. No human corpus, physical radio equipment, verified language benchmark, human listening panel, STOI or PESQ evaluation exists. Tiny Whisper can seriously misrecognize Indic speech, including Kannada. Optional TTS checkpoints remain unavailable until installed. Complete-container recovery is conservative; a single lost packet can fail an entire waveform. Fading assumes ideal CSI and simulator-supplied boundaries. Model loading contributes to cold-start inference time. Local jobs have cooperative cancellation, bounded queue size and upload/duration limits; there is no hard preemption of a running model call. HTTP speech lab calls can take time on CPU. Learned adaptive policy, continuous full-duplex audio and SDR are future work.


Verified on 13 October 2026: English and Hindi semantic speech round trips use local Whisper small; Kannada now uses a pinned public Vakyansh wav2vec2 CTC checkpoint and completed three synthetic speech round trips with native-script text. The old Whisper Kannada wrong-script failure remains in historical evidence. Tamil/Telugu/Malayalam TTS checkpoints are not installed; their shared Whisper checkpoint is present but language-specific recognition quality is not verified. No human-speech accuracy benchmark exists.
